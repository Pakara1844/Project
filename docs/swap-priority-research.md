# ลำดับความสำคัญในการสับเปลี่ยนตัวเก็บประจุ — ทฤษฎี มาตรฐาน และเทียบกับโปรแกรม v9.4

> เอกสารข้อมูลประกอบการตัดสินใจ (ยังไม่แก้โปรแกรม) · 2026-11-16
> ขอบเขต: Capacitor bank แบบ **Double-Wye Ungrounded** ที่ป้องกันด้วยกระแส/แรงดันที่จุด neutral (เช่นของ กฟผ.)

---

## 1. สรุปสั้น

ทั้งมาตรฐานและงานวิจัยมองตรงกันว่า **เป้าหมายจริงของการสับเปลี่ยนไม่ใช่ทำให้ I_no เป็นศูนย์** แต่คือ
**"ไม่ให้ตัวเก็บประจุตัวไหนรับแรงดันเกินพิกัด และให้รีเลย์ยังจับความเสียครั้งถัดไปได้"**
ส่วน I_no เป็นแค่ **ตัวชี้วัด** ของสิ่งนั้น

ลำดับความสำคัญที่เสนอ (มากไปน้อย):

| ลำดับ | สิ่งที่ต้องทำ | ทำไม |
|---|---|---|
| **1** | **เอาตัวเสียออก** (ค่าเพี้ยนเกินพิกัดทั้งทาง**ต่ำและสูง**) | ตัวเสียคือต้นเหตุของแรงดันเกินและการพังต่อเนื่อง (cascading) การปรับสมดุลอาจ "ซ่อน" ตัวเสียจากรีเลย์ได้ |
| **2** | **ไม่มีตัวไหนรับแรงดันเกิน 110% ของพิกัด** | IEEE 18 กำหนดให้ตัวเก็บประจุทนแรงดันต่อเนื่องได้ไม่เกิน 110% ของ rated rms |
| **3** | **I_no ต่ำกว่าเกณฑ์ alarm และมีระยะเผื่อ** | ถ้าค่าค้าง (residual) สูง รีเลย์จะจับความเสียครั้งถัดไปได้ช้าลง |
| **4** | **บาลานซ์ภายในแต่ละ wye** (A=B=C, A'=B'=C') | ทำให้ I_no ≈ 0 และ Mvar/แรงดันแต่ละเฟสเท่ากัน |
| **5** | **ใช้แรงงานและ spare น้อยที่สุด** | เรื่องต้นทุนและเวลาหน้างาน ทำได้หลังจากข้อ 1–4 ปลอดภัยแล้ว |
| 6 | ค่า C รวม/Mvar ใกล้พิกัด | สำคัญน้อย กระทบแค่กำลังรีแอกทีฟที่จ่ายได้ |

## 2. ทฤษฎีพื้นฐาน — ทำไมค่าเหล่านี้สำคัญ

### 2.1 ในสตริงอนุกรม แรงดันแบ่งตามส่วนกลับของ C
แต่ละเฟสต่อตัวเก็บประจุ **อนุกรม** กัน กระแสเท่ากันทุกตัว แรงดันแต่ละตัวจึงเป็น

```
V_unit,i = V_phase × (1/C_i) / Σ(1/C_j)
```

- ตัวที่ **C ต่ำ** (เช่น element ข้างในขาด/ฟิวส์ภายในตัด) → **รับแรงดันมากขึ้น**
- ตัวที่ **C สูง** (เช่น element ข้างในลัดวงจรในแบบ fuseless) → ตัวมันเองรับแรงดันน้อยลง แต่ **element ที่เหลือในตัวนั้น** และ **ตัวอื่นในสตริงเดียวกัน** รับแรงดันมากขึ้น จึงนับเป็นความเสียเหมือนกัน

### 2.2 กลไกพังต่อเนื่อง (cascading failure)
เมื่อ element หนึ่งเสีย แรงดันส่วนนั้นจะไปตกที่ element ที่เหลือ ทำให้ตัวถัดไปเสียง่ายขึ้นเป็นลูกโซ่ จนถึงขั้นระเบิดหรือไฟไหม้ได้
ระบบป้องกัน unbalance จึงถูกออกแบบมาเพื่อ **หยุด bank ก่อนจะถึงจุดนั้น** [TNDI], [SEL-2]

### 2.3 I_no ของ Double-Wye Ungrounded
เมื่อสองฝั่ง wye ต่อ neutral ถึงกัน กระแสที่ไหลผ่าน CT ตรงกลางจะเกิดจาก **ความไม่สมดุลของ C ระหว่างเฟสภายในแต่ละ wye**
- ข้อดี: **ไม่ไวต่อความไม่สมดุลของระบบไฟ** และฮาร์มอนิก zero-sequence เพราะสองฝั่งหักล้างกัน [TNDI]
- ในหน่วย per-unit สัญญาณ neutral current เท่ากับครึ่งหนึ่งของ 3I₂ ของ bank [SEL-2]

## 3. มาตรฐานและงานวิจัยว่าไว้อย่างไร

### 3.1 IEEE Std 18 — ตัวเก็บประจุแต่ละตัว
- ต้องทำงานต่อเนื่องได้ที่ **110% ของ rated rms voltage** (รวมฮาร์มอนิก) และ 120% ของ rated peak [IEEE18-i]
- ทนแรงดันเกินได้ระยะสั้น เช่น 1.40 pu ได้ 15 วินาที, 1.30 pu ได้ 1 นาที (ตามฉบับ 1992) [IEEE18-i]
- ⚠️ ฉบับปัจจุบันคือ IEEE 18-2012 ซึ่งผมเข้าถึงตัวเต็มไม่ได้ ตัวเลข **ค่าเผื่อของ capacitance** จึง **ยังไม่ได้ยืนยัน** ควรเปิดดูจากตัวมาตรฐานหรือ datasheet ของผู้ผลิต

### 3.2 IEEE Std C37.99 — แนวทางการป้องกัน Shunt Capacitor Bank
งาน SEL ที่อ้างอิง C37.99 สรุปแนวคิดการตั้งค่าไว้ดังนี้ [SEL-2]
- **Alarm** ตั้งให้ไวพอจับได้แม้ **ตัวเดียวเสีย** (หรือเสียแค่บาง element)
- **Trip** ตั้งให้ตัด **ก่อนที่แรงดันภายในของตัวที่เหลือจะเกินพิกัด** (ในตัวอย่างใช้ 110% ของ unit rating)
- ⇒ **ค่าที่สำคัญที่สุดในทางป้องกันคือแรงดันเกินของตัวที่ยังดี (overvoltage factor)** ส่วน I_no เป็นสัญญาณที่ใช้ "ส่อง" ค่านั้น
- ข้อสังเกตสำคัญจากเปเปอร์: ถ้าความเสีย **สมมาตรกัน (equalizing failures)** รีเลย์ unbalance จะ **มองไม่เห็นเลย** แม้จะมีแรงดันเกินอยู่จริง
- แนะนำตั้ง alarm ที่ราว 0.8 เท่าของค่าที่คำนวณ เผื่อแรงดันระบบตกลง 20%

### 3.3 วิธีซ่อมจริงจาก Utility (FPL + SEL, IEEE 2014) [SEL-1]
ขั้นตอนที่ใช้งานจริง ย่อได้ว่า
1. ปลด bank, แยก และต่อลงดิน
2. วัดค่า C ทุกตัวเพื่อหาตัวเสีย และวัดค่า spare
3. ใส่ค่าในสเปรดชีต แล้ว **จัดค่าให้บาลานซ์ในสเปรดชีต**
4. **เปลี่ยนตัวเสีย** แล้ว **ย้ายตัวอื่นในแบงค์ถ้าจำเป็น**
5. จ่ายไฟกลับ

**ลำดับในขั้นตอนนี้ตรงกับโปรแกรม:** เปลี่ยนตัวเสียก่อน แล้วค่อยย้ายตัวอื่นเพื่อปรับสมดุล

เปเปอร์ยังระบุว่า **inherent unbalance** (ความไม่สมดุลตั้งต้น) มาจากค่าเผื่อการผลิต อุณหภูมิ และอายุการใช้งาน รีเลย์จึงมีคำสั่ง reset/compensate ค่านี้ ส่วนเวลาหยุด bank ส่วนใหญ่หมดไปกับ **การหาตัวเสีย**

### 3.4 แหล่งรอง (ยังไม่ยืนยันจากมาตรฐาน)
มีคู่มือบางแห่งแนะนำให้ **เปลี่ยนตัวเก็บประจุเมื่อ C ลดลงเกิน ~10%** — ใช้เป็นแนวทางได้ แต่ควรยึดเกณฑ์ของผู้ผลิตหรือ กฟผ. เป็นหลัก

## 4. ตรวจสอบเชิงตัวเลขด้วยเครื่องคำนวณของโปรแกรม

ใช้ `calcYYMetrics` ตัวเดียวกับในโปรแกรม (ตรงกับ Excel) ที่เงื่อนไข **115 kV, 10 ตัวต่อเฟสอนุกรม, ค่าปกติ 27.2 µF**
แรงดันที่แต่ละตัวรับตอนสมดุล = 6.640 kV (คิดเป็น 100%)

| กรณี | I_no (mA) | แรงดันที่ตัว A1 รับ |
|---|---|---|
| (0) แบงค์ปกติ | 0.00 | 100.00% |
| (1) A1 ลดเหลือ 25.0 µF (−8%) | **247.82** | **107.85%** |
| (2) A1=25.0 **และ** A'1=25.0 (เสียสมมาตรข้ามฝั่ง) | **0.00** | **107.85%** ⚠️ |
| (3) ตัว 25.0 อยู่ใน A, B, C ฝั่ง Y1 อย่างละตัว | **0.00** | **107.85%** ⚠️ |
| (4) A1 เพิ่มเป็น 29.5 µF (+8%, element ลัด) | 222.62 | 92.93% (แต่ตัวอื่นในสตริงรับเพิ่ม) |
| (5) เปลี่ยน A1 เป็น spare 27.2 | 0.00 | 100.00% ✓ |

**ข้อสรุปจากตาราง**
- กรณี (2) และ (3) **I_no = 0 (รีเลย์ผ่าน) แต่ตัวที่อ่อนยังรับแรงดันเกินอยู่ 7.85%** → การจัดสมดุลด้วยการสลับตัวเสียเข้าหากันจะ **"ซ่อน" ปัญหาจากรีเลย์** ตรงกับเรื่อง equalizing failures ใน C37.99 [SEL-2]
- วิธีเดียวที่ทำให้แรงดันกลับเป็น 100% คือ **เอาตัวเสียออก** แล้วใส่ตัวดีแทน → ยืนยันว่า **ข้อ 1 ต้องมาก่อนข้อ 3–4**
- ความไวของ I_no ที่ 115 kV / 10 ตัวอนุกรม เมื่อ A1 ตัวเดียวเพี้ยน:

| ค่า A1 (µF) | ลดลงจาก 27.2 | I_no (mA) |
|---|---|---|
| 27.0 | 0.2 (0.7%) | 21.0 |
| 26.8 | 0.4 | 42.3 |
| 26.5 | 0.7 | 74.8 |
| 26.0 | 1.2 | 130.4 |

  → เกณฑ์ 50 mA ≈ ตัวเดียวเพี้ยนราว 0.45 µF (~1.7%), เกณฑ์ **5 mA ≈ เพี้ยนแค่ ~0.05 µF (~0.2%)**
  ควรเทียบกับ **ความแม่นของเครื่องวัด C** ที่หน้างานใช้ ถ้าเครื่องวัดคลาดเคลื่อนมากกว่านี้ เกณฑ์ที่ต่ำมากอาจ "ผ่าน" บนกระดาษแต่ไม่ผ่านจริง *(ตัวเลขนี้ใช้กับ geometry ตัวอย่างนี้เท่านั้น — แบงค์ต่างกันต้องคำนวณใหม่)*

## 5. ลำดับความสำคัญที่เสนอ (อธิบายเต็ม)

1. **ตัวเสียต้องออก** — ตัดสินจากค่าที่วัดเทียบ nameplate/ค่าเผื่อที่ยอมรับได้ **ทั้งต่ำและสูง** ห้ามใช้การสลับเพื่อ "ทำให้ I_no ผ่าน" แทนการเปลี่ยนตัวเสีย
2. **ไม่มีตัวไหนเกิน 110% ของ rated voltage** หลังจัดเรียงแล้ว — ต้องรู้ rated voltage ของตัวเก็บประจุ (จาก nameplate) และคำนวณการแบ่งแรงดันในสตริง
3. **I_no < alarm และเหลือระยะเผื่อ** — ค่าค้างควรเล็กเมื่อเทียบกับสัญญาณของ "ตัวเดียวเสีย" เพื่อให้ alarm ยังจับครั้งถัดไปได้ *(ระยะเผื่อเท่าไร เช่น ≤ 50% ของเกณฑ์ เป็นการตัดสินใจทางวิศวกรรม ไม่ใช่ตัวเลขจากมาตรฐาน — ควรเคาะกับผู้รับผิดชอบรีเลย์ของ กฟผ.)*
4. **บาลานซ์ภายใน wye** — สำหรับ double-wye ข้อนี้แทบเป็นเรื่องเดียวกับข้อ 3 (I_no = 0 ⇔ บาลานซ์ภายใน wye)
5. **ประหยัด spare / จำนวนครั้ง / ระยะเคลื่อนย้าย** — เป็นข้อจำกัดเชิงปฏิบัติ ทำได้หลังจากข้อ 1–4 ปลอดภัยแล้ว
6. **C รวม/Mvar ใกล้พิกัด** — ผลกระทบน้อย

## 6. เทียบกับโปรแกรมปัจจุบัน (v9.4 = logic v6.5)

ลำดับที่โปรแกรมใช้ตอนนี้: **ตัวเสียออกก่อน → ผ่านเกณฑ์ I_no → ระดับที่รบกวนน้อยสุด → spare น้อยสุด → สับน้อยสุด**

| ลำดับที่เสนอ | โปรแกรม v9.4 | ช่องว่าง / ข้อสังเกต |
|---|---|---|
| 1. ตัวเสียออก | ✅ ทำเป็นลำดับแรก (L0 → L1 → L2) | ⚠️ นับเป็น "เสีย" แค่ **< 27 µF** (ด้านเดียว) ตัวที่ **C สูงผิดปกติ** (element ลัด) ไม่ถูกจับ · ตัวที่ต่ำกว่า 27 นิดเดียวแต่ยังอยู่ในค่าเผื่อจะโดนนับเป็นเสีย · ⚠️ เมื่อ spare ดีหมด โปรแกรม **นำตัวที่ถอดออก (ตัวเสีย) กลับมาใส่ชั่วคราว** ตามแบบ v6.5 ซึ่งขัดกับข้อ 1 |
| 2. แรงดันแต่ละตัว ≤ 110% | ❌ ไม่ได้ตรวจ | ไม่ได้คำนวณแรงดันรายตัว และไม่มีช่องกรอก rated voltage — ทั้งที่คำนวณได้จากค่า C ที่มีอยู่แล้ว |
| 3. I_no < เกณฑ์ + ระยะเผื่อ | ✅ ใช้เกณฑ์ที่หน้างานเลือก (5–50 mA) | ⚠️ แนวคิด "ผ่านแล้วหยุด" ยอมรับ I_no ที่ต่ำกว่าเกณฑ์นิดเดียว (เช่น 49 จาก 50 mA) ไม่มีระยะเผื่อ · การเลือกเกณฑ์ต่ำมากควรดูความแม่นของเครื่องวัดประกอบ |
| 4. บาลานซ์ภายใน wye | ➖ แสดงผลอย่างเดียว (ป้าย ΔC เฟส) | สำหรับ double-wye ข้อ 3 ครอบคลุมเกือบทั้งหมดแล้ว — ยอมรับได้ |
| 5. ประหยัด spare/แรงงาน | ✅ spare น้อยสุด → สับน้อยสุด, สลับในเฟสเดียวกัน (ระยะ 1) | สอดคล้องดี |
| 6. C รวม/Mvar | ❌ ไม่ได้พิจารณา | ผลกระทบน้อย |

### จุดที่โปรแกรม "ทำถูก" ตามทฤษฎี
- **ถอดตัวเสียก่อนจัดสมดุล** ตรงกับวิธีซ่อมของ utility และป้องกันการซ่อนความเสียจากรีเลย์ (ข้อ 4 ตาราง (2)/(3))
- **สลับในเฟสเดียวกัน** ตัวเก็บประจุยังอยู่ในเฟสเดิม จึงไม่กระทบระดับแรงดันพิกัดและสัญญาณอ้างอิงเฟส
- **ใช้ I_no แบบ phasor ตรงกับ Excel** ซึ่งเป็นปริมาณเดียวกับที่รีเลย์เห็นจริง

### จุดที่ควรพิจารณาปรับในอนาคต (ยังไม่แก้ — เรียงตามความสำคัญ)
1. **ตรวจแรงดันรายตัวเทียบ 110% rated** (ต้องเพิ่มช่องกรอก rated voltage ของตัวเก็บประจุ)
2. **นิยาม "ตัวเสีย" แบบสองทาง** — เทียบ nameplate ด้วยค่าเผื่อ เช่น ±x% แทนการใช้ "< 27 µF" อย่างเดียว
3. **ไม่นำตัวที่ถอดออกกลับมาใส่** (หรืออย่างน้อยเตือนชัด ๆ) เมื่อ spare ดีไม่พอ
4. **ระยะเผื่อของ I_no** เช่น เป้าหมาย ≤ 50% ของเกณฑ์ แต่ยอมรับได้ถึงเกณฑ์
5. **แนะนำเกณฑ์ตามความแม่นของเครื่องวัด** (แสดงว่าเกณฑ์ที่เลือกเท่ากับกี่ µF ต่อหนึ่งตัว)

## 7. สิ่งที่ยังยืนยันไม่ได้ / ควรตรวจเพิ่ม

- **rated voltage** ของตัวเก็บประจุที่ กฟผ. ใช้ (ต้องดูจาก nameplate) — จำเป็นสำหรับข้อ 2
- **เกณฑ์ alarm/trip จริง** ที่ กฟผ. ตั้งไว้ และนโยบายระยะเผื่อ
- ความแม่นของเครื่องวัด C ที่ใช้หน้างาน
